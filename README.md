# Draconic-Evolution-Automatic-Crafting-Core
This is an WIP Expanction mod for Draconic Evolutoino.
This mod will eventually add Automatic Draconic fusion crafting cores.
When you pipe into the core the first item will go into the core then the others will go into the injectors.
Ideally it will say the Overclock speed in the inventory.
Will automatically start crafting once it sees a valid pattern.
I plan on add 3 Tiers of Auto cores.
  Wyvern Core will let you overclocking to 200%, autostarting, and easy pipeing.
  Draconic Core will let you do 4 of the same craft at once and increases the overclock limit to 400%.
  Chaotic Core will let you do 64 of the same craft at once and removes the overclock limit.
The overclock scales based on the Injector tier.
  Basic +0%
  Wyvern +5%
  Draconic +20%
  Chaotic +100%
You could have up to 36 Injectors around a core however there is not much reason to have more than 10.
